# CodeFive · Técnicos del Mañana

Sistema de entrenamiento adaptativo para técnicos que diagnostican, reparan y mantienen autobuses Volvo.
Proyecto del equipo CodeFive para el Reto 1 de Volvo Group México en el HackaTec Nacional 2026 (InnovaTecNM).

## Qué hace

- Diagnóstico inicial de competencias por grupo de función, nivel y tipo de habilidad
- Ruta de aprendizaje que se adapta a cada técnico
- Práctica de fallas en 3D con pantalla dividida (mouse, cámara o guante)
- Evaluación antes, inmediatamente después y en una revisión diferida simulada
- Tablero para Volvo con avance, dominio, errores y retención en tiempo real

## Stack

Node.js + Express (ES Modules), Handlebars, Vite, Tailwind CSS, Winston + Morgan, SQLite, Socket.IO, Three.js.
